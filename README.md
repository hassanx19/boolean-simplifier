PROJECT IDEA - BEST - BOOLEAN EXPRESSION SIMPLIFICATION TECHNIQUES.

The main goal of this project is to develop a tool where a user can enter the output in a truth table
for some k variables and can get the simplified boolean expression using the two techniques used to simplify
a boolean expression - K-Map and Quine Mc-Kluskey method.
 --> For k<=4 - K-map will be used to simplify the boolean expression
 --> For k>4 - Quine Mc-Kluskey method will be used.
